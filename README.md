# G. Ganesh — Personal Portfolio

**Website:** https://galeti143.github.io/

A responsive personal portfolio built with HTML, CSS and JavaScript. The site is hosted with GitHub Pages.

## Repository structure

- `index.html` — portfolio page, search metadata and Person structured data
- `styles.css` — responsive styling
- `script.js` — navigation, theme and project interactions
- `assets/Ganesh-Public-Resume.pdf` — public resume
- `assets/favicon.svg` — browser tab icon
- `assets/profile-placeholder.svg` — fallback portrait graphic
- `robots.txt` and `sitemap.xml` — search-engine discovery files
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing

## GitHub Pages publishing

This repository is already named `galeti143.github.io`.

1. Open this repository on GitHub.
2. Select **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait for the Pages deployment to finish. Then open https://galeti143.github.io/.

If the site does not appear, open the **Actions** tab and check the latest **pages build and deployment** run for an error. GitHub notes that a change can take up to 10 minutes to publish.

## Help Google find the portfolio

1. Open [Google Search Console](https://search.google.com/search-console/).
2. Add the URL-prefix property `https://galeti143.github.io/` and complete Google's ownership verification.
3. In the Sitemaps report, submit `https://galeti143.github.io/sitemap.xml`.
4. Use URL Inspection for `https://galeti143.github.io/` and select **Request indexing**.

Google decides when to crawl and index the site. A request is not a guarantee of inclusion; indexing can take days or weeks. Search for the distinctive phrase **Galeti Ganesh portfolio**, not only the common name “Ganesh”.

## Privacy

The repository and website are public. The public resume omits date of birth and detailed home address, but the contact section and resume display the phone number and email address. Keep those details only if you want visitors to contact you directly. The original source resume is not included.
